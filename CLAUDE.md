# Админка (admin/)

`admin/` — отдельное Electron-приложение, не входит в сайт (`/admin/` в `.gitignore`). Мама пользуется собранным `.exe`, а не исходниками.

**Правило: после любого изменения файлов внутри `admin/` (main.js, preload.js, src/**) пересобирать `.exe`.**

```bash
cd admin && npm run build
```

Если `npm`/`node` не видны в PATH текущей сессии — добавить путь вручную:
```bash
export PATH="/c/Program Files/nodejs:$PATH"
```

Сборка (`postbuild`) сама копирует готовый файл в `C:\VDIY_Site\Админка.exe` (корень проекта) — именно оттуда его нужно забирать, чтобы передать маме. Промежуточный `admin/dist/` — рабочий вывод electron-builder, не финальная версия для раздачи.
