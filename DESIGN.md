# DESIGN.md — «Уютный уголок»

Одностраничный сайт-визитка для ручных украшений и игрушек. Распространяется среди знакомых (через WhatsApp/Telegram/VK), не продвигается в поиске и не гонится за трендами — задача в том, чтобы сайт выглядел тепло, по-домашнему и вызывал доверие «сделано заботливыми руками», а не «сделано дизайн-агентством».

## 1. Суть и тон

- **Название:** Уютный уголок
- **Тон текста:** простой, дружелюбный, как будто мама сама рассказывает о своих поделках знакомым. Без маркетинговых штампов («эксклюзивный», «премиум»), без канцелярита.
- **Нет блока «о мастере»** — страница сразу ведёт к товарам, короткое приветствие в шапке и всё.
- **Не модно, а уютно**: никаких неонов, градиентов, стекломорфизма, резких теней. Ориентир — тёплый свет, мягкие формы, лёгкая ручная неидеальность (как в фото из Assets — тёплый свет лампы, бархат, мех, нитки).

## 2. Структура страницы (одна колонка, сверху вниз)

1. **Шапка (header, sticky)** — название сайта/логотип + мини-меню с якорными ссылками по категориям + кнопка «Написать» (контакты).
2. **Приветствие (hero)** — 1–2 строки тёплого текста, без портрета и истории. Например: *«Здесь живут украшения и игрушки, сделанные вручную — с теплом и вниманием к мелочам»*.
3. **Категории товаров друг за другом**, в порядке:
   - Украшения (серьги, кулоны, броши — фриволите/макраме)
   - Игрушки (вязаные пушистые зверята-монстрики)
   - Аксессуары / сувениры
   Каждая категория — это `<section id="...">`: заголовок раздела, короткая подпись (необязательно), сетка карточек товаров.
4. **Карточка товара**: фото, название, цена, короткое описание (материал/размер — пара слов), опционально — кнопка «Спросить про этот товар» со ссылкой на WhatsApp/Telegram с заготовленным текстом («Здравствуйте! Интересует …»).
5. **Футер / «Как заказать»**: тёплая финальная фраза + кнопки-ссылки WhatsApp, Telegram, VK. Больше ничего лишнего (копирайт — по желанию, мелким шрифтом).

### Навигация
- Шапка «липнет» к верху при скролле (`position: sticky`), остаётся компактной.
- Пункты меню — якорные ссылки на разделы (`#ukrasheniya`, `#igrushki`, `#aksessuary`), плавный скролл (`scroll-behavior: smooth`).
- На мобильном (главный сценарий — открывают по ссылке из мессенджера на телефоне) меню можно сделать горизontal-scroll строкой из 3 пунктов — пунктов мало, бургер не обязателен.
- Активный раздел можно подсвечивать при скролле — приятно, но не критично для MVP.

## 3. Цветовая палитра

Собрана по фото из `Assets/`: тёплый бежевый фон, мех пушистиков (бурый/зелёный/серый), бархат и ягоды (бордовый), нити фриволите (пыльно-синий, горчично-золотой), жемчуг/кремовый.

| Роль | Цвет | HEX | Где использовать |
|---|---|---|---|
| Фон (основной) | Тёплый кремовый | `#F7F1E6` | Фон страницы — тёплый, не белый |
| Фон карточек | Слоновая кость | `#FFFCF6` | Карточки товаров на фоне страницы |
| Текст основной | Тёплый тёмно-коричневый | `#3B2F26` | Весь текст вместо чёрного |
| Текст приглушённый | Тёплый серо-коричневый | `#7A6C5D` | Подписи, описания товаров |
| Акцент 1 (главный) | Горчично-золотой | `#B9822E` | Заголовки, логотип, акцентные линии, hover |
| Акцент 2 | Пыльно-синий | `#5C6B7A` | Вторичные акценты, бейджи категории «Украшения» |
| Акцент 3 (тёплый, для CTA) | Приглушённый бордовый | `#8C3A34` | Кнопки «Написать»/«Заказать», важные CTA |
| Акцент 4 (зелень) | Лесной зелёный | `#3C6B4E` | Бейдж категории «Игрушки», мелкие детали |
| Линии / границы | Тёплый беж | `#E4D7C2` | Разделители, рамки карточек, тонкие бордеры |
| Тень | `rgba(59, 47, 38, 0.12)` | — | Мягкая тень под карточками (тёплая, не серая) |

Правило: на один экран — фон + текст + максимум 1–2 акцента. Бордовый (Акцент 3) приберечь только для кнопок связи/заказа, чтобы они были заметны.

## 4. Типографика

- **Заголовки (название сайта, заголовки разделов):** мягкий рукописный/акцентный шрифт — например **Caveat** или **Marck Script** (Google Fonts) — используется умеренно: название сайта, H2 разделов. Не весь текст, иначе будет нечитаемо.
- **Основной текст (названия товаров, описания, кнопки):** спокойный скруглённый гротеск — **Nunito**, **Mulish** или **PT Sans** (кириллица обязательно должна поддерживаться). Хорошо читается на телефоне.
- Размеры: заголовок раздела ~28–32px, название товара ~18px, описание/цена ~15px, с достаточным line-height (1.5) для «воздуха».
- Никакого всего-капс (ВСЕ ЗАГЛАВНЫЕ) — это придаёт сайту казённый вид, не уютный.

## 5. Компоненты

### Карточка товара
- Фон слоновая кость, скруглённые углы (`border-radius: 14–18px`), мягкая тёплая тень.
- Фото сверху, кадрировано единообразно (квадрат либо 4:5), тоже со скруглением сверху.
- Внутри: название (акцентный вес), цена (выделена цветом Акцент 1), короткое описание серым, опционально маленькая кнопка «Спросить» цвета Акцент 3.
- При наведении (desktop) — лёгкий подъём карточки (`translateY(-4px)`) и усиление тени, без резких анимаций.

### Кнопки/бейджи категорий
- Небольшой бейдж над названием раздела или в углу карточки, цвет зависит от категории (синий — украшения, зелёный — игрушки, горчичный — аксессуары).

### Разделители между категориями
- Вместо жёсткой линии — тонкий декоративный элемент, отсылающий к рукоделию: пунктир, имитация строчки/стежка (dashed border) или маленький SVG-орнамент (как цветочный росчерк в существующем логотипе).

### Кнопки контактов (футер)
- Крупные, с иконкой мессенджера, тёплый бордовый или цвет самого мессенджера приглушённого тона — главное, чтобы легко нажималось пальцем на телефоне (мин. высота 44px).

## 6. Фото

- Используются собственные фото из `Assets/` (телефонные, с тёплым светом) — это ок и даже хорошо: добавляет «ручной» достоверности. Не нужно заменять на стоковые/идеальные фото.
- Единая лёгкая обработка: естественный тёплый баланс белого, не перенасыщать. Можно слегка подрезать фон, если он отвлекает (как с обоями на фото игрушек), но не обязательно — атмосфера мастерской тоже часть стиля.
- Единообразное кадрирование карточек (одно соотношение сторон) — иначе сетка будет «рябить».

## 7. Адаптивность

- Проектируем mobile-first: большинство переходов — по ссылке из мессенджера на телефоне.
- Сетка товаров: 1 колонка на узком мобильном, 2 — на телефоне шире/планшете, 3 — на desktop.
- Шапка и кнопки — с достаточной областью нажатия под палец.
- Общая ширина контента ограничена (`max-width: ~960px`), по центру — чтобы на desktop не растягивалось «пусто».

## 8. Технический подход

- Простой статичный **HTML/CSS/JS**, без фреймворков и сборки — любой файл можно открыть и поправить напрямую.
- Шрифты — через Google Fonts (с поддержкой кириллицы) либо системные fallback, если нужна работа офлайн.
- Можно разместить на GitHub Pages / Netlify / любом простом хостинге позже — структура файлов под это не требует изменений.

## 9. Чего избегать

- Тёмной темы / чёрного фона — не вяжется с «уютно».
- Крупных модных shadow/glassmorphism эффектов, неоновых градиентов.
- Стоковых иконок соцсетей в ядовитых фирменных цветах на фоне тёплой палитры — лучше приглушённые версии.
- Длинных текстов — страница существует, чтобы показать товары, а не чтобы её читали как блог.
